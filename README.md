# Qaf plugins

Qaf plugins for AI assistants: search and cite classical Arabic Islamic books. Each plugin bundles the Qaf MCP server (`https://api.qaf.ai/mcp`) with a research skill.

| Plugin | What it does |
| --- | --- |
| [qaf](plugins/qaf) | Search classical Arabic Islamic books in English or Arabic, read passages in context, and cite them by book, author and printed page. |

## Install

- **Claude Code:** `/plugin marketplace add qaf-ai/plugins`, then `/plugin install qaf@qaf`.
- **claude.ai and Cowork:** **Customize › Plugins › Add › Add marketplace** with `qaf-ai/plugins`.
- **Codex:** `codex plugin marketplace add qaf-ai/plugins`, then `codex plugin add qaf@qaf` and `codex mcp login qaf` to sign in.

Every client connects to the same server and asks you to sign in to Qaf once.
